# Миссия: Я САМА!

Игра-помощница по домашним делам для Ксюши. Один HTML-файл, папка картинок, работает без интернета.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `index.html` | вся игра целиком — код, вёрстка, логика |
| `img/` | 45 картинок: задания, награды, наряды, аксессуары, фоны |
| `img_backup/` | оригиналы картинок до удаления водяных знаков (в репозиторий не идут) |
| `manifest.json`, `sw.js`, `icon-*.png` | всё, что превращает страницу в приложение на iPad и iPhone |
| `audio/` | необязательная папка: положите сюда `scene-home.mp3`, `task-bed.mp3` и другие записи, и игра будет говорить ими вместо синтеза |

## Как выложить на GitHub Pages

Репозиторий уже создан и зафиксирован, ветка `main`. Осталось отправить его на GitHub.

1. Заведите репозиторий на github.com — кнопка **New**. Имя любое, например `ya-sama`.
   **Не** ставьте галочки «Add a README», «Add .gitignore» — репозиторий должен быть пустым.
2. В папке проекта откройте терминал (правый клик → «Открыть в терминале») и выполните,
   подставив свой логин и имя репозитория:

   ```
   git remote add origin https://github.com/ВАШ_ЛОГИН/ya-sama.git
   git push -u origin main
   ```

   GitHub попросит войти — согласитесь, откроется окно браузера.
3. На странице репозитория: **Settings** → слева **Pages** → в разделе *Build and deployment*
   источник **Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
4. Через минуту-две наверху той же страницы появится адрес вида
   `https://ваш_логин.github.io/ya-sama/`. Это и есть ссылка на игру.

## Как поставить на iPad и iPhone

1. Откройте ссылку в **Safari** (именно в нём, Chrome на iOS так не умеет).
2. Кнопка «Поделиться» внизу → **«На экран Домой»** → Добавить.
3. На рабочем столе появится иконка с Ксюшей. Запускается как обычное приложение:
   на весь экран, без адресной строки, работает без интернета.

Первое открытие должно быть с интернетом — игра скачает картинки в память устройства.
Дальше можно хоть в самолёте.

## Что нужно знать

**Прогресс хранится на каждом устройстве отдельно.** Звёзды, серия дней, купленные наряды на
iPad и на компьютере не связаны между собой. Это не поломка, а устройство браузерного хранилища.
Выберите одно устройство как основное — скорее всего, планшет Ксюши.

**Настройки голоса тоже свои на каждом устройстве.** Наборы голосов у Windows и iOS разные,
поэтому в разделе «Родителям» подберите голос отдельно на планшете.

**Сайт на GitHub Pages открыт всем, у кого есть ссылка,** и репозиторий виден в вашем профиле.
В игре есть имя ребёнка. Если поставите её фотографию аватаркой — она тоже окажется в открытом
доступе. Фото лучше загружать прямо в приложении на планшете (раздел «Родителям» → «Аватар»):
такая картинка хранится только на устройстве и в репозиторий не попадает.

**Родительский режим** — PIN 1234. Поменять можно поиском по `index.html`: строка `'1234'`.

## Как обновлять игру потом

Поправили `index.html` или добавили картинки — в терминале из папки проекта:

```
git add -A
git commit -m "что изменилось"
git push
```

Через минуту обновление доедет до планшета. Если игра открыта — закройте и откройте заново.
